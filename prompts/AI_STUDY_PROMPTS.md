# Codex / Claude Code 학습 프롬프트

아래 요청은 **저장소 루트에서 AI 도구를 실행**하고 사용하는 것을 전제로 합니다.
원하는 파일 경로를 실제 경로로 바꾸세요.

## A. 오늘 작성한 TIL 검토 (수정 없이)

```text
AGENTS.md와 CLAUDE.md의 저장소 규칙을 먼저 확인해줘.
`courses/android-architecture/2026-11-06-my-topic.md`를 읽고 리뷰해줘.
1) 공식 출처와 대조해서 사실관계 오류/과도한 일반화가 있는지
2) 내 설명 중 개념이 빠지거나 애매한 부분
3) 코드가 있다면 동작 원리 및 주의점
4) 내가 추가로 고민할 질문 3개
확인된 근거 URL을 표시하고, 링크의 실제 내용을 열지 못했다면 명시해줘.
파일은 수정하지 말고 피드백만 한국어로 전달해줘.
```

## B. 내가 쓴 TIL을 더 읽기 좋게 다듬기

```text
`courses/android-architecture/2026-11-06-my-topic.md`를 읽어줘.
사용자가 직접 작성한 핵심 이해와 의문점을 유지하면서 문장/목차/중복 표현만 다듬어줘.
기술적 설명이 부정확해 보이면 임의로 고치기보다 '확인 필요'로 주석을 달아줘.
직접 실행하지 않은 실험이나 성능 수치를 만들지 말고, 변경 전후 요약을 먼저 보여줘.
내가 허락하기 전에는 파일을 수정하지 마.
```

## C. 기억을 확인하는 5문제 퀴즈 (정답은 나중에)

```text
`courses/android-architecture/2026-11-06-my-topic.md`를 읽고
Android 실무 경력자 수준의 복습 문제 5개를 만들어줘.
- 개념 확인 객관식 3개, 상황형 단답형 2개
- 정의 암기보다 '왜 그런가, 어떤 문제가 생기는가'를 평가
- 각 질문은 TIL에서 확인된 정보로 답할 수 있게 만들기
- 정답·힌트·해설은 내가 제출하기 전까지 공개하지 않기
- 내가 답하면 문제별 채점 + 근거 + 추가로 공부할 부분을 알려줘
- 문서 파일은 수정하지 마.
```

## D. 학습 요약 / 1분 설명 연습

```text
`courses/android-architecture/2026-11-06-my-topic.md`를 바탕으로
1) 핵심 요약 5줄
2) 면접에서 1분 안에 설명할 수 있는 답변 초안
3) 실무에 적용할 때 주의할 점 2개
4) 문서만으로 확실하지 않은 내용
을 한국어로 정리해줘.
내가 직접 수행하지 않은 경험을 사실처럼 쓰지 마.
```

## E. 한 주 복습 (여러 TIL을 묶어서)

```text
`courses/android-architecture/` 폴더에서 최근 7일 동안 작성한 TIL만 읽어줘.
공통 주제와 서로 연결되는 개념을 설명해주고,
헷갈리기 쉬운 차이 3개, 복습 질문 5개, 다음 주 학습 추천 2개를 제시해줘.
내가 직접 기록하지 않은 학습 완료나 실습 성과는 추정하지 마.
파일은 수정하지 마.
```

## F. 공식 문서 + 내 메모로 TIL 초안 만들기

```text
오늘 학습한 공식 문서 URL: [실제 URL]
내가 직접 쓴 메모:
[핵심 문장 3~5개 붙여넣기]

가능하다면 원문에 접근해서 메모와 비교해줘.
접근이 불가능하면 그 사실을 밝히고, 내 메모를 기반으로만 초안을 만들어줘.
`templates/DAILY_TIL.md` 형태의 초안을 제시하되
'확인된 내용 / 내 해석 / 추가 검증 필요'를 구분해줘.
파일 생성이나 git 작업은 하지 마.
```

## 권장 운영

1. 먼저 직접 메모를 작성합니다.
2. **A → C** 순서로 AI 검토와 퀴즈를 진행합니다.
3. 답변을 확인한 뒤 직접 수정합니다.
4. 필요한 경우만 B 또는 F로 글을 다듬습니다.
5. 최종적으로 사람이 직접 Git commit/push 합니다.

Codex와 Claude Code가 같은 TIL을 동시에 수정하도록 시키지 마세요. 두 도구를 비교할 때는 둘 다 **읽기 전용 검토**로 사용하면 충돌을 피할 수 있습니다.
